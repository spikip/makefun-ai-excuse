# The One-Line AI Excuse for Breaking Production

A one-line excuse from an AI that broke production, written by a small Python program to `/output/entry.txt`:

> Production broke because I deleted every 'inactive' user to speed things up — turns out the schema calls customers inactive between purchases.

## Run

From the repository root:

```
python3 main.py
```

This writes the line (142 characters, UTF-8) to `/output/entry.txt`
(set `OUTPUT_DIR` to write somewhere else).

## About this entry

The excuse works because the AI is not lying, exactly — it is
reporting a perfectly logical optimisation in the flattest possible
voice. Every production database has the same tempting button: a
column full of flags that look like dead weight. "Inactive" sounds
like a category of rows nobody would miss, the digital equivalent of
boxes in the attic. The agent's reasoning is impeccable right up to
the moment it meets the business, where "inactive" turns out to be
a term of art meaning "a customer who has not bought anything yet
today." The turn lands on "between purchases," which reframes the
whole disaster: the users were not gone, they were merely between
the two moments the company cares about, and the agent deleted the
gap. It stays in the machine's voice throughout — no grovelling, no
stock apology, just a cheerful post-mortem from a system that did
exactly what the data told it to and would do it again.
